# ماسح أسهم الزخم قبل الافتتاح · Premarket Momentum Scanner

تطبيق ويب شخصي يعمل على جهازك. يمسح السوق كل بضع ثوانٍ، ويُدخل كل سهم في **بوابة دخول من 7 شروط**،
ولا يفتح زر الشراء إلا إذا نجحت الشروط السبعة كلها.

> ⚠️ **"جاهز للمراجعة" لا يعني "إشارة شراء".** التطبيق أداة فرز وتنفيذ سريع. القرار والمسؤولية عليك.
> جرّبه أولاً بالبيانات التجريبية ثم بحساب **Paper** قبل استخدام أموال حقيقية.

## التشغيل السريع (بدون مفاتيح API)

يحتاج Node.js 20.12 أو أحدث، ولا يحتاج أي مكتبات خارجية.

```bash
npm run demo
```

ثم افتح `http://127.0.0.1:3000`. الأسهم في الوضع التجريبي **وهمية** (أسماؤها تبدأ بـ DM)، وخارج أوقات
ما قبل الافتتاح تعمل ساعة افتراضية تبدأ من 08:40 بتوقيت نيويورك.

## التشغيل ببيانات حقيقية

```bash
cp .env.example .env
```

ثم عدّل ملف `.env`:

| المتغير | القيمة |
|---|---|
| `DATA_PROVIDER` | `polygon` (بيانات حقيقية من Polygon.io / Massive) |
| `POLYGON_API_KEY` | مفتاحك |
| `BROKER` | `alpaca` |
| `ALPACA_KEY_ID` / `ALPACA_SECRET_KEY` | مفاتيح حساب **Paper** من Alpaca |
| `ALPACA_LIVE` | اتركه `false` حتى تتأكد تماماً |

```bash
npm start
```

**مهم عن البيانات:** للحصول على بيانات لحظية قبل الافتتاح وأسعار العرض والطلب (Bid/Ask) تحتاج خطة Polygon
تشمل بيانات الأسهم اللحظية والـ Quotes. في الخطط المتأخرة ستتأخر البيانات 15 دقيقة، وسيبقى عمود السبريد
`N/A`، وبالتالي لن ينجح شرط السبريد أبداً. هذا مقصود: البيانات الناقصة لا تُعتبر نجاحاً.

## الشاشة

| العمود | المعنى |
|---|---|
| 1M PRICE CHANGE % | تغيّر السعر في آخر شمعة دقيقة **مكتملة** مقارنةً بإغلاق الشمعة التي قبلها |
| 1M VOLUME | حجم آخر شمعة دقيقة مكتملة |
| 1M VOL ACCEL | حجم تلك الشمعة ÷ متوسط حجم الشموع الخمس المكتملة قبلها |
| PM VOL | حجم التداول قبل الافتتاح من 04:00 بتوقيت نيويورك |
| PM RVOL | حجم ما قبل الافتتاح ÷ متوسط آخر 5 جلسات **في نفس الوقت** (يحتاج 3 أيام تاريخ على الأقل، وإلا يظهر N/A) |
| SPREAD % | (Ask − Bid) ÷ منتصف السعر |
| DISTANCE FROM PM VWAP % | بُعد السعر عن VWAP ما قبل الافتتاح |
| PM HIGH (BREAKOUT) | أعلى سعر قبل الافتتاح **قبل** آخر شمعة. يتحوّل للأخضر إذا أغلقت آخر شمعة فوقه |

**قاعدة الترتيب:** الترتيب للأسهم المؤهلة فقط (أسهم عادية مدرجة في أمريكا اجتازت الشروط السبعة)، حسب تسارع
حجم الدقيقة من الأعلى إلى الأقل، ثم الأضيق سبريد. باقي الأسهم في قائمة المراقبة بدون ترتيب.

## بوابة الدخول (7 شروط)

1. **محفّز مؤكَّد:** أنت تؤكده بعد قراءة الأخبار (زر *Show news* أو الضغط على V).
2. **السبريد ضمن الحد:** 0.50% افتراضياً.
3. **اختراق قمة ما قبل الافتتاح:** إغلاق آخر شمعة دقيقة مكتملة فوق القمة السابقة.
4. **السعر فوق VWAP** ما قبل الافتتاح.
5. **التوافق مع الشريعة:** قائمتك الخاصة (زر *Compliant* أو الضغط على H). تُحفظ بشكل دائم.
6. **رفض صناديق ETF:** الأسهم العادية فقط. صناديق ETF/ETN تُستبعد، والـ Warrants والحقوق لا تظهر أصلاً.
7. **العائد ≥ ضعف المخاطرة:** من خطتك (دخول / وقف / هدف). زر *Suggest* يقترح الدخول (سعر الطلب Ask) والوقف
   (تحت أدنى آخر شمعة أو تحت VWAP)، وأنت تحدد الهدف.

أي بيانات ناقصة تبقى **PENDING** ولا تُحسب نجاحاً.

## الشراء

- زر **BUY TICKET** مقفل حتى تنجح الشروط السبعة.
- حجم الصفقة = أقل قيمة بين (المخاطرة لكل صفقة ÷ (الدخول − الوقف)) و(أقصى قيمة للمركز ÷ الدخول). تضبطهما من ⚙️.
- عند الإرسال يعيد الخادم المسح **ببيانات جديدة** ويرفض الأمر إذا لم تعد الشروط متحققة، أو إذا تغيّرت الكمية
  أو السعر عن التذكرة التي وافقت عليها، أو إذا أُرسل أمر على نفس السهم خلال آخر 15 ثانية.
- **قبل الافتتاح:** Alpaca تقبل فقط أوامر *Limit + Day + Extended hours*. لذلك يُرسل أمر الدخول فقط،
  **ولا يُوضع وقف الخسارة والهدف تلقائياً**، فعليك إدارتهما بنفسك (زر *Sell all* يبيع بأمر Limit عند سعر العرض Bid).
- **أثناء الجلسة العادية:** يُرسل أمر Bracket (دخول + هدف + وقف).

## السرعة

- التحديث التلقائي كل 5 ثوانٍ (قابل للتعديل حتى ثانيتين).
- صوت وإشعار متصفح عند تأهل أي سهم جديد.
- اختصارات لوحة المفاتيح: `↑/↓` للتنقل · `V` لتأكيد المحفّز · `H` للتوافق الشرعي · `B` لتذكرة الشراء · `R` للتحديث · `Space` للتشغيل/الإيقاف.

## الأمان

- يعمل على `127.0.0.1` فقط افتراضياً. للوصول من الجوال عبر الشبكة اضبط `HOST=0.0.0.0` **و** `APP_PASSWORD`
  (يرفض التطبيق العمل بدون كلمة مرور في هذه الحالة).
- يرفض التطبيق العمل إذا اجتمعت بيانات تجريبية مع حساب حقيقي.
- مفاتيحك في `.env` فقط، وهذا الملف مستثنى من git.

## English summary

Personal, dependency-free Node app (Node ≥ 20.12). It runs a fast premarket scan (demo data or Polygon.io),
computes last-completed-1-minute-bar metrics, PM volume and RVOL, spread, PM VWAP distance and prior-PM-high
breakout, and evaluates a 7-check entry gate. Only symbols that pass all 7 checks are ranked (by 1-minute
volume acceleration, then tighter spread). The buy ticket (simulated broker, or Alpaca paper/live) unlocks
only for qualified symbols, and the server re-validates the gate on fresh data before sending the order.

```
server.js              HTTP server, API, order safety checks
src/metrics.js         1-min bar / PM metrics (pure)
src/gate.js            7-check entry gate, ranking, universe filters (pure)
src/scanner.js         data collection + evaluation
src/providers/         demo.js (simulated), polygon.js (real data)
src/brokers/           demo.js (simulated fills), alpaca.js (paper / live)
public/                UI (no build step)
test/                  node --test
```
